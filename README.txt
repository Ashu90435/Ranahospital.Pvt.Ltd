WHATSAPP:
The form opens WhatsApp with a prefilled message addressed to +91 89531 28683. The student must tap Send in WhatsApp. A static GitHub Pages website cannot silently deliver a WhatsApp message; automatic sending requires a properly configured WhatsApp Business Platform/API and user consent.

GOOGLE MAPS:
The iframe embeds a Google Maps search for the provided address. Since the exact institute pin was not supplied, verify the pin location before publishing. If you have the exact Google Maps share link for the institute, replace the iframe src and map button URL with that location.

PUBLISH ON GITHUB PAGES:
1. Create a GitHub repository.
2. Upload all six files, keeping them in the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the website.

Please verify phone number, address, and actual course offerings before publishing.
